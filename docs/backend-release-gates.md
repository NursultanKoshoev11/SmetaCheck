# Backend release gates

Must be complete before public launch:

- Email register and login with database persistence.
- JWT access token and refresh token sessions.
- Google ID token verification.
- Telegram login signature verification.
- Plan limits before estimate upload.
- File intake with saved estimate status queued.
- Worker status flow from queued to done.
- Report HTML and PDF export.
- Email and Telegram notifications.
- Admin views backed by real data.
