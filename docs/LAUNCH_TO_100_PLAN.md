# SmetaCheck KG — путь к 100% production readiness

Этот документ фиксирует, что уже сделано и что нужно закрыть перед публичным запуском.

## Уже усилено

- Русскоязычный продающий лендинг.
- Основные frontend routes: главная, загрузка, кабинет, отчёты, сравнение, тарифы, помощь, вход.
- Рабочий upload-flow через Go API.
- История загруженных смет через API.
- Скачиваемый текстовый отчёт.
- Реальный parser для XLSX/XLSM/CSV.
- Проверки: пустое наименование, единица измерения, количество, цена, сумма, расхождение количество × цена, возможные дубли, крупные суммы.
- Docker Compose с API, frontend, worker, bot, Postgres, Redis.
- Health/readiness endpoints, CORS, security headers, request id, body limit.

## Что нужно закрыть до настоящих 100%

### P0 — нельзя запускать публично без этого

- PostgreSQL storage для users, projects, estimates, items, findings, reports.
- Авторизация пользователей и защита истории смет по user_id.
- PDF export вместо TXT отчёта.
- HTTPS и production domain.
- Backups PostgreSQL и uploads/reports.
- Error monitoring и uptime monitoring.
- Тесты backend parser/checks на реальных файлах.

### P1 — нужно для нормальной продажи

- Demo Excel файлы и demo reports.
- Форма заявки на демо.
- Страница FAQ.
- Страница “Как проверяется смета”.
- Онбординг для первого клиента.
- Логи действий пользователя.

### P2 — усиление продукта

- Сравнение двух версий сметы на backend.
- PDF parsing или OCR pipeline для PDF.
- Справочник рыночных цен по Кыргызстану.
- Командные роли: владелец, прораб, сметчик, админ.
- Telegram уведомления о готовом отчёте.

## Новая честная оценка после последнего улучшения

- Дизайн/лендинг: 88%
- Frontend routes: 85%
- Upload-flow: 78%
- Backend MVP: 72%
- Реальная проверка смет: 58%
- Production SaaS готовность: 55%
- Готовность для demo-продаж: 82%

## Почему не 100% сейчас

100% означает не только наличие кода. Нужны реальные тесты, безопасность, база, auth, backups, домен, HTTPS, monitoring и проверка на реальных сметах. Сейчас проект уже намного ближе к продаваемому MVP, но ещё не является полноценным production SaaS.
